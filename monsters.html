モンスター一覧

戦闘で出会うモンスターの一覧。通常のモンスター・ボス・没(ゲーム中に戦う場面が無いもの)に分け、登場順に並べている。

  • アンデッド 死戻・死戻強の歌、エニクラウドのターンアンデッド、聖水が成功すると即死する
  • 物理無効 通常攻撃が効かない(クリティカルでも0)
  • 浮遊 地震の歌が効かない。弓・ムチ・手裏剣の通常攻撃の命中率が半分になる(武器屋の説明とは逆で、バグ)

属性(火・水・地・風)の数字はダメージの倍率(%)。100 で普通のダメージ、赤は弱点(150 なら1.5倍)、青は軽減(50 なら半分)、0 はダメージ0。一部の歌・道具では成功率にもなる(下の計算)。
特殊技の数字は、聖水・しびれ薬などの成功率(%)。
行動の%は、1回の行動でそれを選ぶ確率。通常攻撃の近接遠隔は間合いで、命中率が変わる(下の計算)。
出現: ランダムは歩いていて出会う場所、イベントは決まった場所での戦闘。場所は「F番号 地名」で、「全階」「全域」はエンカウントのある階・部屋すべて。
組の 前 後 は敵の前列・後列(前列3体・後列3体まで)。右の%は、その場所で戦闘になったときにその組が出る確率。
逃走は 75% で成功する。イベント戦でも、通常のモンスターだけの戦闘なら逃げられる。ボスが1体でもいる戦闘では「逃走」を選べない。

計算式(▶ をクリックすると開く)

敵の通常攻撃の命中率

割り算の端数は切り捨て

  1. まず、敵の素早さ − 受けるキャラの素早さ を計算する(キャラの素早さは装備の重さで下がった後の値。マイナスにもなる)
  2. その値を 2 で割る(マイナスのときも 0 に近い方へ切り捨て)
  3. その値を 80 に足す → これが基本の命中率(%)
  4. 間合いと列で掛ける:
    • 近接の敵: 敵か受けるキャラのどちらか一方が後列なら ×75%、両方とも後列なら ×40%
    • 遠隔の敵: 列に関係なくそのまま
  5. 受けるキャラが浮遊の状態なら半分にする
  6. 最後に 10〜175% の範囲に収める → これが命中率

例: 素早さ30の近接の敵が、素早さ20のキャラを攻撃
→ 30 − 20 = 10 → 10 ÷ 2 = 5 → 80 + 5 = 85%
→ 両方とも前列なら 85%
→ キャラが後列なら 85×75% = 63.75 → 63%
→ 敵も後列なら 85×40% = 34%
→ 遠隔の敵なら列に関係なく 85%

攻撃の歌のダメージ

炎の槍など。特に書いていなければ端数は切り捨て

  1. まず、主人公のレベルを 3 で割る(端数は四捨五入)
  2. その値に歌の 威力 を掛ける
  3. その値に (100 + LUTE) を掛けて 100 で割る(LUTE はリュート部品の合計)
  4. その値に、敵の 属性の数字 を掛けて 100 で割る → これがダメージ

例: Lv20・LUTE30 で炎の槍(威力17)をレインキャット(火150)に
→ 20÷3 = 6.66… → 7 → 7×17 = 119 → 119×130÷100 = 154 → 154×150÷100 = 231
地震の歌は浮遊の敵には効かない(0)。

歌の成功率

  • 火属性の歌すべて、風属性の歌すべて(冷風も)、氷の矢・落石・土の手・地震: 必ず成功
  • 毒の雨(80)・凍結(80)・幻惑(80)・氷河(60): (基本の成功率 + LUTE) × 敵の 水の数字 ÷ 100
  • 死戻(80)・死戻強(60): (基本の成功率 + LUTE) × 敵の 地の数字 ÷ 100。成功するとアンデッドは即死

( )の中が基本の成功率。例: ゾンビ(地50)に LUTE28 で死戻強 → (60+28)×50÷100 = 44%

道具で敵に与えるダメージ

特に書いていなければ端数は切り捨て

  • 火炎薬: 威力18、敵の 火の数字 を使う
  • 風針薬: 威力18、敵の 風の数字 を使う
  • 爆発薬: 威力25、属性なし(100 として計算)。必ず当たる。ボスには0
  1. まず、使った人のレベルを 2 で割る(端数は切り上げ)
  2. その値に 威力 を掛ける
  3. その値に属性の数字を掛けて 100 で割る → これがダメージ

火炎薬・風針薬は、属性の数字がそのまま成功率にもなる(火10 の敵に火炎薬は 10% しか当たらず、当たってもダメージは1割。100以上なら必ず当たる)。
例: Lv21 で火炎薬をレインキャット(火150)に → 21÷2 = 10.5 → 11 → 11×18 = 198 → 198×150÷100 = 297(必ず当たる)

特殊技の成功率

次の道具・技は、敵の 特殊技の数字 がそのまま成功率(%)。レベルや LUTE は関係しない。100 以上なら必ず成功、ボスには必ず失敗する。

  • 聖水: アンデッドが即死
  • しびれ薬: 行動不能にする
  • 石化薬: 石にする
  • ターンアンデッド(エニクラウドの特技): アンデッドが即死
  • パラライズ(トリリア・パストランの特技): 行動不能にする

例: ゾンビ(特殊技10)に聖水 → 10%。毒ヅタ(特殊技50)にしびれ薬 → 50%

もらえる経験値

仲間1人ずつ、倒した敵1体ずつ計算して合計。端数は切り捨て

  • 仲間のレベルが敵のレベル以下 → カードの EXP の 100%
  • 敵より1つ上 → 70%
  • 2つ上 → 50%
  • 3つ上 → 20%
  • 4つ以上上 → 1(減らした結果が0になるときも 1)

EXP は仲間で分け合わず、戦闘の終わりに立っている仲間がそれぞれ全部もらう(HP 0・逃げた仲間はもらえない)。
例: レインキャット(Lv7・EXP5)→ Lv7以下 5、Lv8 3、Lv9 2、Lv10以上 1
