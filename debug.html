デバッグルームの使い方

開発用に残されたメニュー。隠しコマンドで開き、マップの移動・戦闘・道具や仲間の出し入れなどができる。ここでは各項目でできること・できないことと、実機では反応しない項目の裏側をまとめる。

入り方

タイトル画面で、ボタンを1つずつ次の順に押す。

L2 → L2 → △ → × → SELECT → ○ → □ → L1 → L2 → R2 → SELECT → R1

  • 1回ごとにボタンを離す。違うボタンを押すと最初からやり直し
  • 入力に成功しても画面には何も出ない。そのままゲームを始め(ロードでもよい)、フィールドでセレクトボタンを押すとデバッグルームに入れる
  • 電源を切るまで有効
  • 十字キーの上下で項目を選び、○ボタンで決定、×ボタンでフィールドに戻る

全部で24項目。番号は画面の上から数えた順。灰色の「反応なし」の行は、実機では選んでも何も起きない項目。

アトリビュート表示の見方

  • 薄い白や薄い黒で塗られた部分は歩けない場所
  • 番号のついたマスでは何かの出来事が起きる。同じ番号のマスは同じ出来事(左の画面の「1 1 1」は、3マスのうちどこに触れても1のイベントが起こる)
  • 踏んでも一見何も起きないマスでも、裏でフラグ(話の進み具合の印)が動いていることがある
  • ○ボタンを押すたびに表示のしかたが変わる

デバッグメッセージの見方

段表示意味
1段目FN:○○●●○○がフィールド番号(F 番号)、●●が部屋の番号。階を変えたり建物に入ったりすると変わる
3段目X:○○ Y:○○主人公が今いる場所の座標
ほか何を表しているかは不明

反応なしの項目の裏側

実機で反応しない10項目は、プログラムを調べるとどれも選んだ瞬間に何もせずメニューへ戻る作りになっている(壊れているのではなく、最初からつながっていない)。ただし、そのうち5つは処理の本体がプログラムの中にそのまま残っている。呼び出す道が切られているだけなので、普通に遊ぶ限り絶対に動かない。

パーティー最強処理が残っている

つながっていれば、選んだ瞬間に次のことをする作りだった。

  • 所持金を 99,999 にする
  • パーティーにいる全員の経験値を「レベル99に必要な分」にし、上がれるところまで一気にレベルを上げる(最大レベルが99より低いキャラはそこで止まる)
  • 没の歌も含めて全部の歌(44曲)を覚えた扱いにする。歌詞は書き込まない

装備や道具は変えない。

ＭＡＰ　ＴＥＳＴ / みるみるモード処理が残っている

この2つの間に、使われていない処理が2つ残っている。どちらがどちらの名前のものかは、プログラムからは決められない。

船の航路を見る

  • 「ル－ト番号」(1〜11)を選ぶと、船で移動するときの地図の場面をその番号の航路で流す
  • 見終わると、元のマップ・元の位置に戻る

テスト用のパーティーを組む

  • 2〜4人目をジョーイ・ヴェラ・パストランに入れ替える。パッケージの裏の画面に載っているのと同じ顔ぶれ
  • 4人の装備を次の物にする(今の装備は消える)
頭武器盾体足アクセサリー
リュッケルトターバン石製のナイフラウンドシールドクロースアーマーサンダル守りのペンダント
ジョーイキャップハンドナイフ水の盾キルドレザーミドルブーツだみぃ(没データ)
ヴェラベレー青銅のナイフ火の盾レザーブレストシューズだみぃ(没データ)
パストランフードフレイルヒーターシールドレザーアーマーショートブーツハイネックレス
  • パストランの武器はフレイル(杖)。パストランが装備できる武器種は槍だが、ここではフレイル(杖)が入る。装備の欄に番号を直接書き込む作りで、そのキャラが装備できるかどうかは確かめない
  • リュートの部品を 絹の弦・茶色の胴・１２弦指板・蝶ネック・肌色／茶の線・水晶の装飾 にする
  • 歌を6曲(炎の槍・炎の柱・炎爆発・凍結・土の手・台風)覚えた扱いにする
  • レベル・経験値は変えない
モンスター戦闘パターン変更処理が残っている
  • 「通常 / 特殊１＝１００％ / 特殊２＝１００％」の3択の画面が残っている
  • 選んだ値を読む仕組みは戦闘の側にも残っていて、「特殊１」なら敵が毎回1つ目の特殊技を使う(通常攻撃と2つ目の技の確率を 0% にする)、「特殊２」なら毎回2つ目の特殊技を使う。特殊技を持たない敵は変わらない
パーティー戦闘パターン変更処理が残っている
  • 「通常 / 特殊＝１００％ / 逃げ＝１００％ / 守り＝１００％」の4択の画面が残っている
  • 仲間が勝手に動く処理(自動行動)がこの値を読んでいて、「特殊」なら必殺技・呪文を必ず使う、「逃げ」なら必ず逃げる
  • ただし、効くかどうかはキャラによって違う。下の表のとおり
キャラ勝手に動く処理特殊＝１００％逃げ＝１００％
ホイヒュー・ドムカ・スリム・クイクイ・エニクラウド・ヴェラ・トリリア・グラム・ヘンケン・ライオネル・ショウコ・パストラン・トラビス・フィデレ・ドンキー・サザシイ・マキバ・シベリン(没)ある必ず必殺技・呪文を使う必ず逃げる
ピックマン・アロン・エド・ボビンある設定を読まない → 変化なし必ず逃げる
ジョーイ・アイリスある(回復の呪文)必ず回復を唱える(ジョーイはギガヒーリング、アイリスはテラヒーリング)逃げる処理がそもそも無い → 逃げない
ドロシー・リュッケルト無い(何もせず命令どおり)設定を読まない → 変化なし設定を読まない → 逃げない
  • ジョーイ・アイリスとドロシー・リュッケルトは、結果はどちらも「逃げない」だが理由が違う。前の2人は設定を読んだうえで逃げる処理が無く、後の2人は設定をまったく読まない
  • 「守り」を読むキャラはいない

このことから、ピックマン、アロン、エド、ボビンには技が予定されていた→開発途中で無くなったという可能性が見えてくる。

モニターメーター表示・ＳＡＶＥ・ＬＯＡＤ・ＵＮＦＯＲＭＡＴ・戦闘アニメーションコマ送り跡なし
  • デバッグルームの処理の中に、この5つ用の処理は見つからない。名前だけが残っている
  • ふつうのセーブ・ロードは別の処理なので、これらとは関係ない

デバッグルームでもできないこと

  • 主人公をパーティーから外す
  • 最初のレベルより下げる、すでに上がった能力値を下げる
  • 特定の能力値だけを増やす・減らす
  • 所持金を増やす・減らす(お金が欲しいときはエメラルドを手に入れて売る、などで代わりになる)
  • 覚えた歌を忘れさせる
  • 捨てられない物を処分する(道具を減らす機能は無い)
  • もう見たイベントをもう一度起こす(物によってはできる)。フラグを書き換える機能は無い
  • 敵の行動(命中率を含む)を操る、味方の技や命中率を操る
  • SP が減らない・道具が減らない・ダメージを受けない、のような無敵にする
  • 固まったときに戻す、ソフトリセット
デバッグルームをむやみに使うと普通のプレイに支障が出る
  • 話を進めるのに必要なキャラがパーティーにいない→イベントが起きない
  • 夢の城をクリアしたとき、パーティーがシナリオキャラで埋まっている→誰かを外さないといけないのに誰も外せず、「誰を解雇しますか」で堂々巡り
  • 本来ならその時点で持っているはずの物が無い、または立てているはずのフラグが立っていないまま、先の町でセーブしてしまうと回収の手立てがなくなる

例えば、トラビスが加わってすぐに外し、フエダの町でセーブすると、沼地の案内役がいなくて進めなくなる。酒場に行ってもトラビスはもういないので、呼び戻す方法が無い(もう一度デバッグルームを開いてトラビスを仲間に入れれば直る)。
